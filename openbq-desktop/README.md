# OpenBQ Desktop

Electron app for Open Biometric Quality Assessment (OpenBQ). This package contains the desktop UI, Electron main process, and build/distribution configuration.

**Status**: internal app in active development.

**Tech Stack**
- Electron (main + preload)
- React + TypeScript + Vite (renderer)
- Tailwind CSS
- Electron Builder (packaging)

**Repository Layout (Package)**
- `src/` — React renderer (UI)
- `electron/` — Electron main + preload sources
- `electron-dist/` — compiled Electron main/preload output
- `public/` — static assets
- `assets/` — extra resources bundled into releases
- `build/` — signing and platform build configs

## Prerequisites
- Node.js (use the version pinned by the repo tooling if applicable)
- npm (workspaces enabled)

If you are building signed macOS artifacts, you will also need the signing credentials referenced in `vars.sh`.

## Local Development
From the repo root (recommended):
```bash
npm install
npm -w openbq-desktop run electron:dev
```

From this package directory:
```bash
npm install
npm run electron:dev
```

The dev command runs the Vite dev server and then launches Electron once the server is ready.

## Build
Build the renderer and Electron main process:
```bash
npm -w openbq-desktop run electron:build
```

If you need only the renderer or Electron main:
```bash
npm -w openbq-desktop run build:ui
npm -w openbq-desktop run build:electron
```

## Distribution
Packagers are wired via Electron Builder. Common targets:
```bash
npm -w openbq-desktop run dist:osx
npm -w openbq-desktop run dist:unsigned
npm -w openbq-desktop run dist:linux
```

On macOS, signed builds require the env variables sourced by `vars.sh`. Unsigned builds use `dist:unsigned`.

From the monorepo root, shared packages are typically built first:
```bash
npm run build:shared
npm -w openbq-desktop run electron:build
```

## Configuration
AI settings (e.g., model/provider) are managed in-app and persisted in local storage. No runtime config file is required for standard dev workflows.

## Notes
- Electron entrypoint: `electron-dist/main.js` (generated by `build:electron`).
- Preload script: `electron/preload.cjs` is copied into `electron-dist/` during build.
